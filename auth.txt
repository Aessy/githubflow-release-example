Authentication
==============
User model:
  - id, email, password (bcrypt cost 12), created_at

Endpoints:
  POST /auth/login    — returns signed JWT (1h expiry)
  POST /auth/refresh  — issues new token, invalidates old
  POST /auth/logout   — adds token to deny-list

Rate limiting:
  - Login attempts capped at 10 per IP per minute
  - Excess requests receive 429 Too Many Requests
  - Counter resets on successful login

Error codes:
  400  malformed request body
  401  invalid credentials or expired token
  422  missing required fields
  429  rate limit exceeded
