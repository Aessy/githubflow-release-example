Authentication
==============
User model:
  - id, email, password (bcrypt), created_at

Login endpoint  POST /auth/login
  Request:   { "email": "...", "password": "..." }
  Response:  { "token": "<jwt>", "expires_at": "<iso8601>" }
  Errors:    401 bad credentials, 422 missing fields

Token behaviour:
  - Expiry:    1 hour from issuance
  - Refresh:   POST /auth/refresh  { "token": "..." }
               Returns new token; old token is immediately invalidated
  - Logout:    POST /auth/logout   { "token": "..." }
               Token added to deny-list until original expiry passes
