Task Listing & Search
=====================
GET /tasks
  Auth:    Bearer token required
  Returns: paginated, filtered, sorted task list

Query parameters:
  page, per_page (max 100), status, sort, order
  q         string  Full-text search across title and description

Response:
  { "data": [...], "total": N, "page": N, "pages": N }

Search behaviour:
  - Case-insensitive substring match on title and description
  - Results ranked by relevance when q is supplied (sort param ignored)
  - Empty q is equivalent to omitting the parameter
