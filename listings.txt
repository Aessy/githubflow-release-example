Task Listing & Search
=====================
GET /tasks
  Auth:    Bearer token required
  Returns: paginated, filtered, sorted task list

Query parameters:
  page, per_page (max 100), status, sort, order
  q         Full-text search across title and description
  assignee  UUID  Filter by assigned user (admin only for other users)

Search behaviour:
  - Case-insensitive substring match on title and description
  - Results ranked by relevance when q is supplied
  - Assignee filter returns 403 if non-admin requests another user's tasks
