Task Listing
============
GET /tasks
  Auth:    Bearer token required
  Returns: paginated array of tasks for the authenticated user

Query parameters:
  page      int     Page number, 1-based (default: 1)
  per_page  int     Results per page, max 100 (default: 20)
  status    string  Filter by status (open|in_progress|done|cancelled)
  sort      string  Field to sort by: created_at|updated_at|title (default: created_at)
  order     string  asc|desc (default: desc)

Response:
  {
    "data":  [ ...task objects... ],
    "total": 142,
    "page":  1,
    "pages": 8
  }
