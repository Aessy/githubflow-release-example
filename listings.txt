Task Listing & Search
=====================
GET /tasks
  Auth:    Bearer token required
  Returns: paginated, filtered, sorted task list

Query parameters:
  page, per_page (max 100), status, sort, order
  q         Full-text search across title and description
  assignee  UUID  Filter by user (admin only for other users)

Response headers:
  X-Total-Count   total matching records
  X-Page-Count    total pages
  Link            RFC 5988 next/prev/first/last rel links

Cursor-based pagination (preferred for large sets):
  Use cursor=<opaque_token> instead of page; returns next_cursor in body.
  cursor and page params are mutually exclusive — 400 if both supplied.
