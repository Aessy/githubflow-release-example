User Permissions and Teams
==========================
Team model: id, name, owner_id, members[{user_id, role}]
Task sharing: optional team_id; roles control read/update/delete/assign

Permission matrix:
  member=read only, editor=read+update+priority,
  manager=all, task-owner=all except manage-members, admin=all

Audit log:
  - All permission-sensitive actions (task update/delete, role change,
    member add/remove) written to an append-only audit log per team
  - GET /teams/:id/audit   paginated, manager or admin only
  - Entries retained for 90 days
