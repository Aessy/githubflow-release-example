User Permissions and Teams
==========================
Team model:
  - id, name (unique), owner_id, created_at
  - members: array of { user_id, role: member | editor | manager }

Endpoints:
  POST   /teams                    Create team
  GET    /teams                    List teams the caller belongs to
  GET    /teams/:id                Team details and member list
  PATCH  /teams/:id                Update name (manager or owner)
  DELETE /teams/:id                Delete team (owner only)
  POST   /teams/:id/members        Invite user { "user_id": "...", "role": "member" }
  PATCH  /teams/:id/members/:uid   Change role
  DELETE /teams/:id/members/:uid   Remove member (manager+ or self)
