Activity Feed
=============
GET /users/me/activity
  Returns reverse-chronological events the caller was involved in.

Event types surfaced in feed:
  task.created      task.updated     task.status_changed
  comment.created   mention.received reminder.triggered
  team.joined       team.role_changed

Query params:
  types     Comma-separated list of event types to include
  since     ISO 8601 — only events after this timestamp
  per_page  Max 50 (default 20)
  cursor    For cursor-based pagination
