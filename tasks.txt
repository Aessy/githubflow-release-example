Task Management
===============
Task model:
  - id, title (1-200), description (opt, 2000), status, owner_id, created_at, updated_at

Create task  POST /tasks
  Auth:      Bearer token required
  Request:   { "title": "...", "description": "..." }
  Response:  201  { "id": "...", "title": "...", "status": "open", ... }
  Errors:    401 unauthenticated, 422 validation failure

Update task  PATCH /tasks/:id
  Request:   any subset of { title, description, status }
  Response:  200  updated task object
  Errors:    401, 403 not owner, 404 not found, 422 validation

Delete task  DELETE /tasks/:id
  Response:  204 No Content
  Errors:    401, 403, 404
