Task Management
===============
Task model:
  - id, title (1-200), description (opt, 2000), status, owner_id, created_at, updated_at

Endpoints:
  POST   /tasks        Create task (auth required)
  PATCH  /tasks/:id    Update task (owner or admin)
  DELETE /tasks/:id    Delete task (owner or admin)
  GET    /tasks/:id    Fetch single task (any authenticated user)

Status transitions (enforced server-side):
  open  →  in_progress  →  done
  open  →  cancelled
  in_progress  →  cancelled
  Attempts to move backwards return 422 with reason "invalid_transition".
