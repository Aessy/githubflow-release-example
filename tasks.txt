Task Management
===============
Task model:
  - id, title (1-200), description (opt, 2000), status, owner_id, created_at, updated_at

Endpoints:
  POST   /tasks        Create task (auth required)
  PATCH  /tasks/:id    Update task (owner only)
  DELETE /tasks/:id    Delete task (owner only)

Ownership rules:
  - owner_id is locked to the JWT sub claim at creation time
  - Attempting to modify or delete another user's task returns 403
  - Admins (role=admin in JWT) may operate on any task
