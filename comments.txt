Task Comments
=============
Comment model:
  - id, task_id, author_id, body (1-5000), created_at, updated_at, deleted_at

Endpoints:
  POST/GET  /tasks/:id/comments
  PATCH/DELETE  /tasks/:id/comments/:cid

Mentions:  @username  →  notification, resolved at write time, max 10
Markdown:  raw body + rendered_html in responses

Reaction emoji:
  POST   /tasks/:id/comments/:cid/reactions   { "emoji": "👍" }
  DELETE /tasks/:id/comments/:cid/reactions/:emoji
  - One reaction per emoji per user per comment
  - GET comment response includes reactions: { "👍": 3, "🎉": 1, ... }
