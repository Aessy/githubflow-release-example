Task Priorities
===============
Priority field: critical | high | normal | low  (default: normal)

Sorting:  ?sort=priority  (combinable with secondary sort)
SLA targets: critical 4h, high 24h, normal 24h, low best-effort

Bulk priority update:
  PATCH /tasks/bulk-priority
  Request:  { "ids": ["uuid1", "uuid2"], "priority": "high" }
  Response: 200 { "updated": 2, "skipped": 0 }
  - Only updates tasks the caller owns (or all if admin)
  - Tasks not found or not owned are silently skipped (counted in "skipped")
