Task Priorities
===============
Priority field: critical | high | normal | low  (default: normal)
Bulk update: PATCH /tasks/bulk-priority  { ids, priority }

Priority escalation rules:
  - A task not updated within its SLA window is automatically escalated one level
  - Escalations are logged as an audit event on the task
  - Escalation can be disabled per-task: PATCH /tasks/:id  { "auto_escalate": false }
  - Admins receive a daily digest of all escalated tasks
